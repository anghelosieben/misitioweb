Novedades en Angular 21

Nuevo

Componentes Diferidos

carga diferida de componentes con la directiva @defer, mejorando significativamente los tiempos de carga inicial.

ejemplo.component.html 
@defer (on interaction) {
  <app-chat></app-chat>
}
Nuevo

Event Signal Inputs

Los inputs ahora pueden ser funciones que reaccionan a cambios, permitiendo un binding de eventos más intuitivo.

mi-componente.ts 
import { input, output } from '@angular/core';

export class MiComponente {
  onClick = output<MouseEvent>();
  title = input<string>();
}
Nuevo

Control Flow Syntax

La nueva sintaxis de control de flujo con @if, @for, @switch es ahora el padrão recomendado.

ejemplo.component.html 
@for (item of items; track item.id) {
  <p>{{ item.name }}</p>
} @empty {
  <p>No hay elementos</p>
}
Nuevo

Zoneless Change Detection

Soporte experimental para aplicaciones sin Zone.js, usando signals para una detección de cambios más eficiente.

Componentes

Los componentes son los bloques fundamentales de una aplicación Angular. Cada componente encapsula su propia lógica, estilos y plantilla.

Componente Básico

Estructura mínima de un componente standalone en Angular 21.

mi-componente.ts 
import { Component } from '@angular/core';

@Component({
  selector: 'app-mi-componente',
  standalone: true,
  template: `<h1>Hola Mundo</h1>`,
  styles: [`h1 { color: #dd0031; }`]
})
export class MiComponente {}

Con Inputs y Outputs

Comunicación entre componentes padre e hijo usando input y output.

tarjeta.component.ts 
import { Component, input, output } from '@angular/core';

@Component({
  selector: 'app-tarjeta',
  standalone: true,
  template: `
    <h2>{{ titulo() }}</h2>
    <button (click)="onEliminar.emit(id())">Eliminar</button>
  `
})
export class TarjetaComponent {
  titulo = input<string>();
  id = input<number>();
  onEliminar = output<number>();
}

Servicios

Los servicios son clases que encapsulan lógica de negocio y se injectan usando el sistema de inyección de dependencias de Angular.

Servicio Básico

Un servicio injectable que proporciona datos a los componentes.

datos.service.ts 
import { Injectable } from '@angular/core';

@Injectable({
  providedIn: 'root'
})
export class DatosService {
  obtenerDatos() {
    return [{ id: 1, nombre: 'Angular' }];
  }
}

Uso en Componente

Inyección del servicio en el constructor del componente.

lista.component.ts 
import { Component, inject } from '@angular/core';
import { DatosService } from './datos.service';

@Component({
  selector: 'app-lista',
  standalone: true
})
export class ListaComponent {
  private datosService = inject(DatosService);
  datos = this.datosService.obtenerDatos();
}

Routing

El enrutamiento permite navegación entre vistas sin recargar la página.

Configuración de Rutas

Definición de rutas con loadComponent para código splitting automático.

app.routes.ts 
import { Routes } from '@angular/router';

export const routes: Routes = [
  { path: '', loadComponent: () => import('./home') },
  { path: 'productos', loadComponent: () => import('./productos') },
  { path: 'productos/:id', loadComponent: () => import('./detalle') },
  { path: '**', redirectTo: '' }
];

Navegación con RouterLink

Enlace declarativo a rutas en la plantilla.

nav.component.html 
<nav>
  <a routerLink="/" routerLinkActive="active">
    Inicio
  </a>
  <a routerLink="/productos" routerLinkActive="active">
    Productos
  </a>
</nav>
<router-outlet></router-outlet>

Obtención de Parámetros

Acceso a parámetros de ruta con input signals.

detalle.component.ts 
import { Component, inject } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  standalone: true
})
export class DetalleComponent {
  private route = inject(ActivatedRoute);
  ngOnInit() {
    const id = this.route.snapshot.paramMap.get('id');
  }
}

Signals

Los signals son una nueva forma de manejar el estado reactivo en Angular, ofreciendo mejor rendimiento y deducción automática de dependencias.

Signal Básico

Creación y uso de signals para estado reactivo.

contador.component.ts 
import { Component, signal } from '@angular/core';

@Component({
  standalone: true,
  template: `
    <button (click)="incrementar()">Contador: {{ contador() }}</button>
  `
})
export class ContadorComponent {
  contador = signal(0);

  incrementar() {
    this.contador.update(v => v + 1);
  }
}

Computed Signals

Señales derivadas que se actualizan automáticamente cuando cambian sus dependencias.

tienda.component.ts 
import { Component, signal, computed } from '@angular/core';

export class TiendaComponent {
  precio = signal(100);
  cantidad = signal(2);
  
  total = computed(() => this.precio() * this.cantidad());
}

Efectos (Effects)

Ejecutar código side-effect cuando las señales cambian.

efecto.component.ts 
import { Component, signal, effect } from '@angular/core';

export class EfectoComponent {
  usuario = signal<string|null>(null);

  constructor() {
    effect(() => {
      console.log('Usuario changed:', this.usuario());
    });
  }
}

Directivas Estructurales

Las directivas estructurales manipulan el DOM añadiendo o removiendo elementos.

@if - Condicional

Renderizado condicional de contenido.

ejemplo.component.html 
@if (usuario) {
  <p>Hola {{ usuario.nombre }}</p>
} @else if (cargando) {
  <p>Cargando...</p>
} @else {
  <p>No hay usuario</p>
}

@for - Iteración

Iteración sobre colecciones con track para performance.

ejemplo.component.html 
@for (producto of productos; track producto.id) {
  <li>
    {{ producto.nombre }} - {{ producto.precio | currency }}
  </li>
} @empty {
  <li>No hay productos disponibles</li>
}

@switch - Selección

Selección entre múltiples casos.

ejemplo.component.html 
@switch (estado) {
  @case ('activo') {
    <span class="badge success">Activo</span>
  }
  @case ('pendiente') {
    <span class="badge warning">Pendiente</span>
  }
  @default {
    <span class="badge">Desconocido</span>
  }
}

HTTP Client

Angular proporciona HttpClient para realizar peticiones HTTP a APIs REST.

Configuración

Proveer HttpClient en la aplicación.

app.config.ts 
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [provideHttpClient()]
};

Peticiones GET

Obtener datos de una API con observables y signals.

api.service.ts 
import { Component, inject, signal } from '@angular/core';
import { HttpClient } from '@angular/common/http';

export class ApiService {
  private http = inject(HttpClient);
  
  obtenerUsuarios() {
    return this.http.get<User[]>('https://api.ejemplo.com/users');
  }
}

POST con Tipado

Enviar datos a una API con tipado completo.

formulario.component.ts 
crearUsuario(datos: NuevoUsuario) {
  return this.http.post<Usuario>(
    'https://api.ejemplo.com/users',
    datos
  );
}

Comparación de Síntaxis

Característica Sintaxis Antigua Sintaxis Nueva (@)
Condicional *ngIf="cond; else elseBlock" @if (cond) { } @else { }
Iteración *ngFor="let item of items" @for (item of items; track item.id) { }
Switch [ngSwitch]="valor" @switch (valor) { @case { } @default { } }
Input @Input() nombre: string nombre = input<string>()
Output @Output() evento = new EventEmitter() evento = output<void>()
