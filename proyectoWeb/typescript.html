Introducción a TypeScript

TypeScript es un superset tipado de JavaScript que compila a JavaScript puro. Añade tipos estáticos, clases e interfaces.

✓

Tipado Estático

Detecta errores en tiempo de desarrollo, no en ejecución

O

Type Inference

TypeScript infiere tipos automáticamente cuando es posible

C

Compilación

Compila a JavaScript estándar compatible con cualquier navegador

E

ES Next

Soporta todas las características modernas de ECMAScript

Instalación y Uso

terminal 
// Instalar TypeScript globalmente
npm install -g typescript

// Verificar versión
tsc --version

// Compilar un archivo
tsc archivo.ts

// Compilar con watch mode
tsc --watch archivo.ts

Tipos Básicos

TypeScript soporta los tipos primitivos básicos de JavaScript más algunas adiciones.

Básico

String, Number, Boolean

Tipos primitivos fundamentales en TypeScript.

tipos-basicos.ts 
let nombre: string = "Juan";
let edad: number = 25;
let activo: boolean = true;

// Type inference - infiere automáticamente
let ciudad = "Madrid"; // string
let temperatura = 20.5; // number
Básico

Array y Tuple

Colecciones de elementos con tipos definidos.

arrays.ts 
// Array de strings
let frutas: string[] = ["manzana", "pera"];
let numeros: Array<number> = [1, 2, 3];

// Tuple - array con tipos fijos
let par: [string, number] = ["edad", 30];
let respuesta: [boolean, string] = [true, "éxito"];
Básico

Enum

Conjunto de constantes nombradas.

enums.ts 
enum Estado {
  Activo = "ACTIVO",
  Inactivo = "INACTIVO",
  Pendiente = "PENDIENTE"
}

enum Prioridad {
  Baja,    // 0
  Media,   // 1
  Alta     // 2
}

let estadoActual: Estado = Estado.Activo;
Básico

Any y Unknown

Para valores de tipo desconocido.

any-unknown.ts 
// any - desactiva el chequeo de tipos
let variable: any = "hola";
variable = 42; // permitido

// unknown - tipo seguro para valores desconocidos
let valor: unknown = "texto";
if (typeof valor === "string") {
  console.log(valor.toUpperCase());
}
Básico

Null, Undefined y Void

Tipos para valores nulos y funciones sin retorno.

nulos.ts 
let nada: null = null;
let indefinido: undefined = undefined;

// void para funciones que no retornan nada
function saludar(): void {
  console.log("Hola");
}

// never para funciones que nunca terminan
function error(): never {
  throw new Error("Error fatal");
}
Básico

Union Types

Una variable puede ser de varios tipos.

union.ts 
let id: string | number = "abc123";
id = 123; // válido

type Resultado = "éxito" | "error" | null;

function procesar(valor: string | number) {
  if (typeof valor === "string") {
    return valor.toUpperCase();
  }
  return valor * 2;
}

Interfaces

Las interfaces definen la estructura que debe seguir un objeto. Son fundamentales para el tipado fuerte.

Interface Básica

Definir la forma de un objeto.

interface-basica.ts 
interface Usuario {
  id: number;
  nombre: string;
  email: string;
  edad?: number; // opcional
  readonly createdAt: Date; // solo lectura
}

const usuario: Usuario = {
  id: 1,
  nombre: "María",
  email: "maria@ejemplo.com",
  createdAt: new Date()
};

Extend, Index Signature

Interfaces compuestas y dinámicas.

interface-avanzada.ts 
interface Animal {
  nombre: string;
}

interface Mascota extends Animal {
  dueno: string;
}

// Index signature para propiedades dinámicas
interface Diccionario {
  [clave: string]: string;
}

const traduccion: Diccionario = {
  hello: "hola",
  world: "mundo"
};

Function Interfaces

Definir la firma de una función.

function-interface.ts 
interface Operacion {
  (a: number, b: number): number;
}

const sumar: Operacion = (x, y) => x + y;
const multiplicar: Operacion = (x, y) => x * y;

Tipos Avanzados

Características avanzadas de TypeScript para crear tipos complejos y reutilizables.

Avanzado

Type Alias

Crear nombres alternativos para tipos.

type-alias.ts 
type ID = string | number;
type Fecha = string | Date;

type Config = {
  apiUrl: string;
  timeout: number;
  retry: boolean;
};

type SoloLectura<T> = {
  readonly [P in keyof T]: T[P];
};
Avanzado

Discriminated Unions

Uniones con propiedad discriminante para type narrowing.

unions.ts 
type Solicitud =
  | { tipo: "exito"; datos: string }
  | { tipo: "error"; mensaje: string }
  | { tipo: "carga" };

function procesar(req: Solicitud) {
  switch (req.tipo) {
    case "exito":
      return req.datos;
    case "error":
      return req.mensaje;
    case "carga":
      return "Cargando...";
  }
}
Avanzado

Template Literal Types

Crear tipos a partir de plantillas de strings.

template.ts 
type Evento = "click" | "scroll" | "hover";
type Handler = `on${Capitalize}`;
// Handler = "onClick" | "onScroll" | "onHover"

type Columnas = "a" | "b" | "c";
type Propiedad = `col-${Columnas}`;
// Propiedad = "col-a" | "col-b" | "col-c"
Avanzado

Conditional Types

Tipos que dependen de otros tipos.

conditional.ts 
type EsString<T> = T extends string ? true : false;

type A = EsString<string>;  // true
type B = EsString<number>; // false

type ExtraerNombre<T> = T extends { nombre: infer U } ? U : never;
type Nombre = ExtraerNombre<{ nombre: string; edad: number }>;
// string
Avanzado

Mapped Types

Transformar tipos existentes en nuevos tipos.

mapped.ts 
// Hacer todas las propiedades opcionales
type Parcial<T> = {
  [P in keyof T]?: T[P];
};

// Hacer todas las propiedades requeridas
type Requerido<T> = {
  [P in keyof T]-?: T[P];
};

// Transformar propiedades a tipo diferente
type Stringify<T> = {
  [P in keyof T]: string;
};

Funciones

TypeScript extiende las capacidades de las funciones de JavaScript con tipado completo de parámetros y retornos.

Parámetros y Retorno

Funciones con tipos explícitos.

funciones.ts 
function saludar(nombre: string): string {
  return `Hola, ${nombre}!`;
}

// Parámetros opcionales
function crearUsuario(
  nombre: string,
  edad?: number
): string {
  return edad ? `${nombre}, ${edad}` : nombre;
}

// Parámetros con valores por defecto
function incrementar(valor: number, delta: number = 1): number {
  return valor + delta;
}

Funciones Flecha

Sintaxis moderna con tipado completo.

arrow.ts 
const duplicar = (n: number): number => n * 2;

const procesarTexto = (texto: string, mayusculas: boolean = false): string => {
  return mayusculas ? texto.toUpperCase() : texto.toLowerCase();
};

// Funciones como parámetros
function ejecutar(fn: (a: number) => number, valor: number): number {
  return fn(valor);
}

Rest Parameters y Overloads

Parámetros variables y múltiples firmas.

rest-overload.ts 
// Rest parameters
function sumar(...numeros: number[]): number {
  return numeros.reduce((a, b) => a + b, 0);
}

// Function overloads
function parse(input: string): string[];
function parse(input: number): number;
function parse(input: string | number): string[] | number {
  if (typeof input === "string") {
    return input.split("");
  }
  return input;
}

Genéricos

Los genéricos permiten crear componentes y funciones que funcionan con múltiples tipos sin perder información.

Genéricos Básicos

Funciones y tipos que aceptan cualquier tipo.

generics-basico.ts 
// Función genérica
function identidad<T>(valor: T): T {
  return valor;
}

const num = identidad<number>(42);
const txt = identidad("hola"); // infiere T = string

// Interface genérica
interface Contenedor<T> {
  valor: T;
  obtener(): T;
}

Restricciones (Constraints)

Limitar los tipos que puede usar un genérico.

constraints.ts 
// Debe tener propiedad length
function longitud<T extends { length: number }>(item: T): number {
  return item.length;
}

longitud("hola");     // 4
longitud([1, 2]); // 2

// Extender de un tipo específico
interface Identificable {
  id: string;
}

function buscarPorId<T extends Identificable>(
  items: T[],
  id: string
): T | undefined {
  return items.find(item => item.id === id);
}

Genéricos con Múltiples Tipos

Varios parámetros de tipo en una función.

multi-generics.ts 
// Pares clave-valor
function crearPar<K, V>(clave: K, valor: V): { clave: K; valor: V } {
  return { clave, valor };
}

const par = crearPar("edad", 30);
// { clave: string; valor: number }

// Utility types con genéricos
type ClaveValor<K extends string, V> = {
  [P in K]: V;
};

Clases Genéricas

Clases que trabajan con tipos genéricos.

clase-generica.ts 
class Pila<T> {
  private elementos: T[] = [];

  apilar(elemento: T): void {
    this.elementos.push(elemento);
  }

  desapilar(): T | undefined {
    return this.elementos.pop();
  }
}

const pilaNumeros = new Pila<number>();
pilaNumeros.apilar(1);
pilaNumeros.apilar(2);

Clases

TypeScript soporta clases con modificadores de acceso, herencia, abstract classes y más.

Clase Básica con Modificadores

public, private, protected, readonly.

clase.ts 
class Usuario {
  public nombre: string;
  private email: string;
  protected id: number;
  readonly createdAt: Date;

  constructor(nombre: string, email: string) {
    this.nombre = nombre;
    this.email = email;
    this.id = Math.random();
    this.createdAt = new Date();
  }

  getEmail(): string {
    return this.email;
  }
}

Herencia y Override

Extender clases y sobrescribir métodos.

herencia.ts 
class Animal {
  constructor(public nombre: string) {}

  hablar(): void {
    console.log("Sonido");
  }
}

class Perro extends Animal {
  constructor(nombre: string, public raza: string) {
    super(nombre);
  }

  hablar(): void {
    console.log("Guau!");
  }
}

Abstract Classes

Clases base que no se pueden instanciar directamente.

abstract.ts 
abstract class Figura {
  abstract calcularArea(): number;
  
  mostrarArea(): void {
    console.log(`Area: ${this.calcularArea()}`);
  }
}

class Circulo extends Figura {
  constructor(public radio: number) {
    super();
  }

  calcularArea(): number {
    return Math.PI * this.radio ** 2;
  }
}

Implement e Interfaces

Una clase puede implementar múltiples interfaces.

implement.ts 
interface Volable {
  volar(): void;
}

interface Nadable {
  nadar(): void;
}

class Pato implements Volable, Nadable {
  volar(): void {
    console.log("Volando");
  }

  nadar(): void {
    console.log("Nadando");
  }
}

Utility Types

TypeScript incluye tipos utilitarios integrados para transformar tipos existentes.

Partial, Required, Readonly

Modificadores de propiedad.

modifiers.ts 
interface Usuario {
  id: number;
  nombre: string;
  email: string;
}

type UsuarioParcial = Partial<Usuario>;
type UsuarioRequerido = Required<Usuario>;
type UsuarioSoloLectura = Readonly<Usuario>;

// Ejemplo de uso
function actualizarUsuario(
  id: number,
  datos: Partial<Usuario>
): void {
  // datos puede tener cualquier subconjunto de Usuario
}

Pick, Omit, Exclude, Extract

Selección y exclusión de propiedades.

select.ts 
interface Usuario {
  id: number;
  nombre: string;
  email: string;
  password: string;
}

// Solo ciertas propiedades
type UsuarioPublico = Pick<Usuario, "id" | "nombre" | "email">;

// Excluir propiedades
type SinPassword = Omit<Usuario, "password">;

// Excluir de union types
type SoloNumeros = Exclude<string | number | boolean, boolean | string>;
// Result: number

type SoloBoolean = Extract<string | number | boolean, boolean>;
// Result: boolean

Record y Map

Crear tipos para diccionarios y mapas.

record.ts 
// Record: objeto con claves y valores tipados
type Roles = "admin" | "user" | "guest";
type Permisos = Record<Roles, boolean>;

const permisos: Permisos = {
  admin: true,
  user: true,
  guest: false
};

// Diccionarios de objetos
type Usuarios = Record<string, { nombre: string; edad: number }>;

ReturnType y Parameters

Extraer tipos de funciones.

function-types.ts 
function crearUsuario(nombre: string, edad: number) {
  return { id: Math.random(), nombre, edad };
}

type UsuarioCreado = ReturnType<typeof crearUsuario>;

type Params = Parameters<typeof crearUsuario>;
// [nombre: string, edad: number]

// Parámetros como tupla
type PrimerParametro = Params[0]; // string

NonNullable y Awaited

Filtrar tipos.

filter.ts 
// Eliminar null y undefined
type Limpio = NonNullable<string | number | null | undefined>;
// string | number

// Obtener tipo de Promise resuelta
type Resultado = Awaited<Promise<string>>;
// string

async function fetchUsuario() {
  return { nombre: "Juan" };
}

type Usuario = Awaited<ReturnType<typeof fetchUsuario>>;

Resumen de Utility Types

Utility Type Descripción Ejemplo
Partial<T> Todas las propiedades opcionales Partial<Usuario>
Required<T> Todas las propiedades requeridas Required<Usuario>
Readonly<T> Todas las propiedades solo lectura Readonly<Usuario>
Pick<T, K> Seleccionar propiedades Pick<Usuario, 'id' | 'nombre'>
Omit<T, K> Excluir propiedades Omit<Usuario, 'password'>
Record<K, V> Objeto con claves K y valores V Record<string, number>
ReturnType<T> Tipo de retorno de función ReturnType<typeof fn>
Parameters<T> Tipos de parámetros Parameters<typeof fn>
